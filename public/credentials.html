The test users (login, password, token) the server types for you. A credential set is a named group of fields, for example username and password, and it is bound to the origins where it may be used: a password is never typed on any other site. Routines and AI agents only name the set (admin-test) and the field; they never see the value. Values are write-only: once saved, nothing can read them back, not this page, not the API. Every change needs an admin's API key, typed below: it is kept in this page's memory only and forgotten after 5 minutes without use or when you leave.
