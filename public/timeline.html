How the system evolved

What changed in a target's screens from one build to the next, read from the stored snapshots: a field, an action or a grid column that appeared, changed or went away, and in which build. Type a control key (its name or id, as in the inventory) to see when it was first seen and where it is now. Only the structure of screens is compared, never the data they hold.
