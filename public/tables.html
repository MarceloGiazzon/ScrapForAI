Tables of cases

Loading…

A table of cases is a CSV with the inputs of a test and the result it must give: one row is one case. A routine reads a column as the values it types (fromTable) and another as the result the page must show (expected.table), so a suite with as many samples as rows runs every case. Each save is a new, immutable version: saving the same content again makes no new version, and a run says which version it used. The first line holds the column names (letters, digits, _ and -); , or ; separate the cells (a Portuguese or Spanish spreadsheet saves with ; and a decimal comma). Put test data here, never a password or a key: the server refuses a cell that looks like one.
