Schedules start runs on their own (a routine, the regression vault, a system-evolution snapshot or a periodic summary). Webhooks are the channels (Slack, Teams, Google Chat or a generic JSON endpoint) that hear when a schedule goes from green to red and back, and receive the periodic summary. Both start browsers or send data out of the server without anyone watching, so every change needs an admin's API key, typed below: it is kept in this page's memory only and forgotten after 5 minutes without use or when you leave. A webhook's URL is a secret (anyone holding it can post as the channel): it is write-only, like a password, and the server only ever shows its origin.
